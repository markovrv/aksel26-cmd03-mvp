Голосовой AI-ассистент
с распознаванием речи

Voice Stream превращает ваш смартфон в умный микрофон. Речь транскрибируется через faster-whisper, обрабатывается LLM и озвучивается обратно — всё за доли секунды.

Возможности

Всё, что нужно для голосового AI

От распознавания до синтеза речи — единое WebSocket-соединение и полный контроль через браузер.

🎤

Распознавание в реальном времени

faster-whisper на CUDA обрабатывает PCM-аудиопоток 16 кГц. VAD-детекция автоматически определяет границы фраз и фильтрует тишину.

🧹

Фильтрация галлюцинаций

4-уровневая система отсеивает ложные срабатывания Whisper: чёрный список, подстроки, стоп-слова и контекстная проверка.

💬

LLM-чат с историей

Любой OpenAI-совместимый API (YandexGPT, OpenAI, Ollama). Системные промпты, история сессии, управление контекстом.

🔊

Синтез речи (TTS)

Два режима: браузерный SpeechSynthesis и серверный Silero TTS (v4, русский язык). Несколько голосов: xenia, aidar, baya и другие.

🔄

Диалоговый режим

Каждая распознанная фраза автоматически отправляется в LLM. Ассистент отвечает без лишних действий — настоящий разговор.

⏳

Режим «Ожидание»

После паузы в речи LLM сам спрашивает «Что дальше?». Настраиваемый таймаут и порог шума для естественного диалога.

🎧

Режим «Наушники»

TTS не приостанавливает распознавание. Можно слушать ответ ассистента и продолжать говорить — идеально для диктовки.

📝

Суммаризация лога

Весь диалог отправляется в LLM для краткого пересказа. Результат скачивается как отчёт — готовый протокол встречи.

📂

Управление промптами

CRUD для системных промптов прямо из интерфейса. Сохраняйте сценарии под разные задачи — переключение в один клик.

Архитектура

Как это устроено

Единое WebSocket-соединение (WSS) связывает браузер с Python-сервером. Аудиопоток, транскрипция, LLM-запросы и TTS — всё в одном канале.

📱 Браузер → PCM audio (16kHz) 🐍 Python-сервер → JSON 📱 Браузер
GetUserMedia → ScriptProcessor faster-whisper + VAD Silero TTS / SpeechSynthesis LLM API (OpenAI-совместимый)
Транспорт: WSS (WebSocket Secure) · Порт 8765 · Самоподписанный SSL

Технологии

Стек проекта

Минимум зависимостей, максимум контроля. Сервер на чистом asyncio, клиент без единого фреймворка.

Python 3.x + asyncio faster-whisper (CUDA) PyTorch Silero TTS v4 WebSocket Secure (WSS) OpenAI-compatible API YandexGPT Web Audio API SpeechSynthesis API PCM Int16 (16/24 kHz) VAD (Voice Activity Detection) HTML/CSS/JS (vanilla)
